All tools

Every JudgeIP tool for IP lookup, leak testing, routing and network diagnostics, grouped by purpose.

IP lookup

IP check Location, ASN, residential vs. hosting, fit for 8 use cases, risk signals, DNSBL blocklists, BGP/RPKI and multi-database geolocation. Checkup Checks six things at once: IP, WebRTC, DNS, time zone and language consistency, automation fingerprints and AI service access. Whois / RDAP lookup Registration data and lifecycle for domains, IP ranges and ASNs, straight from each registry's RDAP service. DNS records & blocklists (DNSBL) Look up A/AAAA/MX/TXT/NS records for a domain, or the PTR record and four common spam blocklists for an IPv4 address. IP / CIDR calculator Netmask, wildcard mask, first and last usable address and size for IPv4 and IPv6 ranges. IP card Generate an IP summary card with optional address masking. Download as PNG or copy as Markdown.

Network and edge

Global ping Ping an IP or domain from probes in 13 regions at once and compare latency and packet loss. Connectivity Whether 44 well-known sites in and outside China (AI, social, developer) are reachable, and how fast. Cloudflare edge check Which Cloudflare colo you hit and how far it is, Turnstile results, HTTP/3 and WARP status. CDN edge nodes Which city each of twenty CDNs (Fastly, CloudFront, Akamai, EdgeOne and more) routes you to. Split routing test Which exit IP dozens of sites (China-based, international and AI) each see, to confirm your proxy routing rules work. Service status Official status pages of major AI, cloud and developer services in one place, to see whether the problem is on their side.

Leaks and fingerprinting

WebRTC leak test Queries STUN servers in and outside China one by one to see whether your proxy leaks your real UDP address. DNS leak test Resolves random subdomains in parallel to find the recursive DNS servers that actually resolve names for you, and their networks. Browser fingerprint How identifiable your browser is, using FingerprintJS v3 / v2 and TLS JA3 / JA4. HTTP headers & UA See the HTTP headers, language preferences and Client Hints the server actually receives, and spot headers added by transparent proxies.

AI

AI access check Whether ChatGPT, Claude, Gemini, Grok and others are reachable, and whether your exit is in a supported region. Claude check Estimates from 10 browser signals (time zone, language, fonts and more) whether you are likely to be classified as a user in China.
