Contact us

Data corrections, feature feedback and business inquiries are all welcome through the channels below. There is no support ticket system — mail is read directly by the maintainer, usually answered within 1-3 working days.

Email

hi@judgeip.com

To help us locate the problem quickly, please include:

  • Data corrections: the specific IP address, the field you believe is wrong, and the evidence you have (for example, you operate the IP or hold a more authoritative source). We verify each item against the upstream records before replying.
  • Broken features: the page URL, browser and version, steps to reproduce; screenshots help.
  • Upstream data sources: if you own one of the data sources this site references and have concerns about how it is used, say so directly and it will be prioritized.
  • Partnerships and API volume: the free tier is documented in the API docs; requirements beyond it can be discussed by mail.

Security issues

If you have found a security vulnerability — for example, a way to bypass rate limits, read other visitors' lookups or tamper with scores — please mail hi@judgeip.com with "Security" in the subject. Please do not disclose the details publicly before a fix is deployed. There is no bug bounty program, but we will credit you in the fix notes unless you prefer to stay anonymous.

Abuse complaints

Lookup results on this site are aggregations of public data. The site hosts no user content and does not provide proxy or VPN services. If you believe a page nevertheless infringes your rights, mail us the specific page and the reason, and we will review it.

Response time

Mail is usually answered within 1-3 working days. Data corrections may take longer because they often need confirmation from the upstream source. If a week passes without a reply, feel free to send it again — mail is never deliberately ignored.
