什么是分流

Clash、Surge、Shadowrocket、sing-box 这类代理软件通常有三种模式：直连（全部不走代理）、全局（全部走代理）、 规则（按域名或 IP 归属逐条判断）。规则模式就是所谓的「分流」：命中 GEOSITE,CN、 GEOIP,CN 这类规则的国内网站直连，其余走代理节点；讲究一点的配置还会为 AI、流媒体、加密货币单独指定节点， 比如让 ChatGPT 与 Claude 固定走美国的住宅 IP，让币安走新加坡。

规则一多，实际效果就很难凭配置文件判断：域名有没有写全、规则的先后顺序、DNS 解析发生在哪里，都会让某个网站走到你没想到的出口。 最直接的验证办法是问网站本身——每个网站看到的那个 IP，就是你的流量到它那里时实际用的出口。

这次检测做了什么

  1. 对清单里的每个网站，从你的浏览器直接发一个跨域请求，不带 Cookie、不带来源页。
  2. 接入 Cloudflare 的网站请求 /cdn-cgi/trace，读出其中的 ip（它看到的你）、loc（这个 IP 所在国家）与 colo（你命中的 Cloudflare 机房）。
  3. 网易、字节跳动几行请求各自 CDN 上的测速文件，读响应头里回显的访客地址；它们只给 IP，国家取自看到同一出口（同一 IP，IPv6 为同一 /64 网段）的其他网站。
  4. 8 路并发、单项最长等 6 秒；失败的网站分别在 2 秒、4 秒后各重试一次。主域名不通时换备用域名再问一次：Cloudflare 中国网络换 perfops.cloudflareperf.com，unpkg 换 unpkg.com。
  5. 按出口 IP 把结果归成几个出口，比较国内组与国外组、AI 组与其他国外网站的出口，给出结论。IPv4 与 IPv6 只在同一族里比较，双栈网络不会被误判成分流；IPv6 按 /64 网段归并——同一台设备的临时地址会在网段内轮换，有的代理也按连接换源地址，它们仍是同一个出口。

所有请求都由你的浏览器直接发出，本站服务器不参与、也收不到任何结果。唯一由服务器给出的是「JudgeIP 服务器看到的地址」那一行， 它是你打开本页时连到本站的地址，用来和其他网站看到的地址对照。

怎么读检测结果

  • 分流正常：国内组的网站看到的出口在中国，国外组的在海外。这是规则模式应有的样子。
  • 所有网站走同一出口：没有分流。出口在中国说明根本没走代理；出口在海外说明代理开着全局模式——如果你本来就在海外、没开代理，这也是正常的。
  • 国内网站也走了代理：国内站点绕到了海外节点。访问会变慢，部分国内服务会把你当成海外用户，检查规则里的国内直连部分。
  • AI 流量单独分流：AI 网站的出口和其他国外网站不同，说明为 AI 单独设置的规则生效了。
  • AI 出口位于不支持的地区：AI 网站看到的出口在中国大陆、香港、澳门、俄罗斯等地，ChatGPT 与 Claude 在这些地区不提供服务，需要换节点。
  • IPv4 与 IPv6 走了不同出口：常见于代理只接管了 IPv4，支持 IPv6 的网站绕开了代理直连。

出口汇总里点一下就能复制完整的 IP，再到首页查询它的归属、接入类型与风险记录； 想确认 AI 服务的完整支持地区，见 AI 解锁检测；每个网站能不能打开、延迟多少，见网络连通性； 你命中的 Cloudflare 机房、WARP 状态与各等级网络的节点对比，见 Cloudflare 节点检测。

常见问题

显示「所有网站走同一出口」，是不是代理没生效？
不一定。它只说明这几十个网站看到的是同一个地址：要么完全没走代理（出口就是你本地的运营商），要么代理开在全局模式（出口是代理节点）。看出口所在的国家就能分清：在中国大陆是前者，在海外是后者。想要国内直连、国外走代理，需要在 Clash、Surge、Shadowrocket 这类软件里切到「规则」模式。
国内网站检测出来是海外 IP，会有什么影响？
访问国内网站要先绕到海外节点再回来，速度明显变慢；视频、音乐、网银等国内服务会按 IP 把你判定为海外用户，可能出现版权内容看不了、登录要额外验证，甚至触发风控。通常是代理软件开着全局模式，或者规则里缺了国内域名、GEOIP,CN 这类直连规则。
AI 网站的出口在香港，为什么提示不支持？
OpenAI 与 Anthropic 都不向中国大陆、香港、澳门提供服务，俄罗斯、白俄罗斯、伊朗、朝鲜、叙利亚、古巴等地区同样不在名单内。出口落在这些地区时，网页可能打不开、注册会被拒，已有账号也可能因此被标记。本页只按这份通用名单提醒一句，各家服务完整的支持地区见本站的 AI 解锁检测。
为什么有的网站显示「该站未开放 IP 头」或「连接失败」？
网易、字节跳动几行读的是响应头里的 IP，浏览器只有在对方明确开放（Access-Control-Expose-Headers）时才让网页读到，对方没开放就只能显示这一句。其余网站读的是 Cloudflare 的 /cdn-cgi/trace，失败多半是该站在你的网络里被屏蔽、超时，或者它已经不走 Cloudflare。失败的站点会自动再试两次，个别站点失败不影响整体结论。
本站会保存分流检测的结果吗？
不会。每个请求都由你的浏览器直接发给对应的网站，不带 Cookie、不带来源页，读到的地址只显示在当前页面里，不会发回本站。「JudgeIP 服务器看到的地址」一行是本站在你打开页面那一刻看到的连接地址，这一页不缓存，也不和检测结果一起保存。
