全部工具

JudgeIP 的全部 IP 查询、泄露检测、路由与网络诊断工具，按用途分组。

IP 查询

IP 纯净度检测 归属地、ASN、原生 IP、8 类用途适配、风险信号、DNSBL 黑名单、BGP/RPKI 与多库定位。 环境体检 同时检查 IP、WebRTC、DNS、时区与语言是否一致、自动化指纹和 AI 服务可用性，共 6 项。 平台检测 ChatGPT、Claude、Netflix、TikTok 等平台各自怎么看这个 IP：能读到出口的直接比对，读不到的按 IP 属性推断并标明。 多 IP 对比 一次最多 6 个 IP，并排列出评分、网络类型、原生 IP、代理标记、黑名单和每一项的加减分。 原生 IP 检测 注册国家和定位国家是否一致，加上网络类型、代理标记和黑名单，权重列在页面上。 住宅 IP 检测 是住宅、移动网络还是机房 IP，有没有代理标记、黑名单记录和多余的开放端口。 TikTok IP 检测 按住宅或移动网络、原生 IP、代理标记、黑名单四项打分，另外对比浏览器时区和语言。 Whois / RDAP 查询 域名、IP 段、ASN 的注册信息与生命周期，直接来自各注册局的 RDAP 服务。 DNS 解析与黑名单 (DNSBL) 查询域名的 A/AAAA/MX/TXT/NS 记录，或查 IPv4 的 PTR 和 4 个常用垃圾邮件黑名单。 IP / CIDR 子网计算器 计算 IPv4 与 IPv6 网段的子网掩码、反掩码、首尾可用地址与网段容量。 IP 信息分享卡片 生成 IP 信息卡片，可给地址打码，支持下载 PNG 或复制 Markdown。

网络与节点

全球 Ping 从 13 个地区的探针同时 Ping 一个 IP 或域名，比较各地延迟与丢包。 网络连通性 国内外 44 个知名网站、AI 服务、社交与开发站点能不能连上、延迟多少。 我的出口 国内、国外、IPv6、WebRTC 等通道各自看到的出口 IP 汇总成一张表，判断有没有分流或泄露。 Cloudflare 节点检测 命中的 Cloudflare 机房与距离、Turnstile 人机验证结果、HTTP/3 与 WARP 状态。 CDN 命中节点 Fastly、CloudFront、Akamai、EdgeOne 等二十家 CDN 各自把你调度到哪个城市。 网站分流测试 数十个国内外与 AI 网站分别看到你的哪个出口 IP，验证代理分流规则是否生效。 服务状态 汇总主流 AI、云服务与开发工具的官方状态页，确认是不是对方在故障。

泄露与指纹检测

WebRTC 泄露检测 国内外 STUN 服务器逐台探测，判断代理有没有漏掉真实 UDP 地址。 DNS 泄露检测 并发随机子域探测，找出真正替你解析域名的递归 DNS 服务器与归属网络。 浏览器指纹检测 用 FingerprintJS v3 / v2 与 TLS JA3 / JA4 三种算法看浏览器有多容易被识别。 HTTP 请求头与 UA 解析 查看服务器实际收到的 HTTP 请求头、语言偏好与 Client Hints，排查透明代理加的头。

AI 相关
