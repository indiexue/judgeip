IP 纯净度与查询

IP 纯净度检测 归属地、ASN、原生 IP、8 大场景适配、风险与 DNSBL 黑名单、BGP/RPKI 及多库定位。 一键环境体检 同时对 IP 纯净度、WebRTC、DNS、时区语言一致性、自动化指纹与 AI 准入做 6 大维度交叉校验。 Whois / RDAP 查询 域名、IP 段、ASN 的注册信息与生命周期条，直接来自各注册局的 RDAP 服务。 DNS 解析与黑名单 (DNSBL) 查询域名 A/AAAA/MX/TXT/NS 权威记录，或反查 IPv4 PTR 与 4 家主流垃圾黑名单。 IP / CIDR 子网计算器 计算 IPv4 与 IPv6 网段的子网掩码、反掩码、首尾可用地址与网段容量。 IP 信息分享卡片 生成可一键隐私打码的 IP 纯净度报告卡，支持下载高清 PNG 或嵌入论坛 Markdown。

网络与节点

全球 Ping 从世界各地 13 个地区探针同时 Ping 一个 IP 或域名，比较各地延迟与丢包。 网络连通性 国内外 44 个知名网站、AI 服务、社交与开发站点能不能连上、延迟多少。 Cloudflare 节点检测 命中的 Cloudflare 机房距离、Turnstile 人机验证通过率、HTTP/3 与 WARP 状态。 CDN 命中节点 Fastly、CloudFront、Akamai、EdgeOne 等二十家 CDN 各自把你调度到哪个城市。 网站分流测试 数十个国内外与 AI 网站分别看到你的哪个出口 IP，验证代理分流规则是否生效。 服务状态 汇总主流 AI、云厂商与开发服务官方状态页，排查是不是对方正在故障。

泄露与指纹检测

WebRTC 泄露检测 国内外 STUN 服务器逐台探测，判断代理有没有漏掉真实 UDP 地址。 DNS 泄露检测 并发随机子域探测，找出真正替你解析域名的递归 DNS 服务器与归属网络。 浏览器指纹检测 FingerprintJS v3 / v2 与 TLS JA3 / JA4 三种算法看你的浏览器有多好认。 HTTP 请求头与 UA 解析 查看服务器收到的真实 HTTP 标头、语言偏好与 Client Hints，排查透明代理头泄露。
