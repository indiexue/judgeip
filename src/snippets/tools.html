全部工具

judgeip.com 的全部检测与查询工具，按用途分组。

IP 查询

IP 检测 归属地、ASN、网络类型、威胁与代理情报、IP 评分，以及多家地理库的多库定位。 Whois 查询 域名、IP 段、ASN 的注册信息，直接来自各注册局的 RDAP 服务。 全球 Ping 从世界各地的探针同时 Ping 一个 IP 或域名，比较各地延迟与丢包。

网络与节点

网络连通性 国内外网站、AI 服务、社交与开发站点能不能连上、延迟多少。 Cloudflare 节点检测 你命中的 Cloudflare 机房、Cloudflare 看到的出口、HTTP/3 与 WARP 状态。 CDN 命中节点 Fastly、CloudFront、Akamai 等十多家 CDN 各自把你调度到哪个城市。 网站分流测试 数十个网站分别看到你的哪个出口 IP，分流规则有没有生效。 服务状态 打不开某个服务时，先看是不是对方官方状态页上正在故障。

泄露检测

WebRTC 泄露检测 国内外 STUN 服务器逐台探测，判断代理有没有漏掉真实地址。 DNS 泄露检测 从本站自持的权威 DNS 反查是谁在替你解析域名。 浏览器指纹检测 FingerprintJS v3 / v2 与 JA3 / JA4 三种算法看你的浏览器有多好认。

AI 相关

AI 解锁检测 ChatGPT、Claude、Gemini、Grok 等能否访问，出口是否在支持地区。 Claude 检测 时区、语言、字体等 10 项浏览器信号，估算会不会被判成中国用户。
