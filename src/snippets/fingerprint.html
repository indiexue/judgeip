什么是浏览器指纹

浏览器指纹（Browser Fingerprinting）是一种无状态的识别方法。 Cookie 是网站在你的设备上写一个标记，下次访问再读回来，你可以删掉或拒收。 指纹不写任何东西，只收集浏览器本来就会告诉网站的属性， 算出一个哈希值作为你的编号。删 Cookie 没用，无痕模式也没用，因为没有任何东西被保存。

单独一项属性的信息量很小，用 Chrome 的人有几十亿。但几十项组合在一起，重合的概率就会迅速下降： 屏幕 2560×1440、时区 Asia/Shanghai、装了 187 种字体、显卡是 Apple M2、 音频栈算出的浮点数尾数是某个特定值……每多一项，可能的组合数就再乘上一个倍数。 电子前哨基金会（EFF）2010 年的 Panopticlick 实验显示， 在开启 Flash 或 Java 的浏览器里，超过九成的样本是唯一的。

三种算法的差别

FingerprintJS v3+

目前主流的开源实现。v3 和旧版最大的区别是取舍标准： 不再尽量多采集，只保留跨会话稳定的信号。 User-Agent 这种一升级就变、又能随意伪造的字段，权重被大幅降低甚至去掉； Canvas 渲染差异、WebGL 显卡与驱动信息、音频处理特征、字体度量这些和硬件、系统绑定的信号成为主要依据。 所以稳定性更高：同一台设备换网络、换时区，visitorId 通常不变。 本页加载的是 v3.4.2，MIT 协议的开源版本，完全在本地计算，不联网。

FingerprintJS2（旧版）

2015 到 2020 年间广泛使用的版本，采集范围更广： 插件列表、Flash 字体、触摸支持、CPU 类型、Do-Not-Track 标志等。 这些信号现在大多已被浏览器削弱或屏蔽（Chrome 早已不再暴露真实插件列表）， 所以旧版的哈希在现代浏览器上反而不如新版稳定。 保留它是为了对照：同一台设备两个算法的结果不一致，正好能看出这几年浏览器在隐私上收紧了多少。

JA3 / JA4

前两种都在 JavaScript 里运行，改改浏览器设置或装个反指纹扩展就能干扰。 JA3 / JA4 在另一层：它读的是 TLS 握手时客户端发出的第一个报文（ClientHello）， 把其中的 TLS 版本、密码套件、扩展、椭圆曲线及点格式按固定顺序拼成字符串再取哈希。 这些内容由浏览器底层的 TLS 库决定，网页里的 JavaScript 改不了， 所以它识别的是你在用哪个版本的哪款浏览器（或哪个爬虫库），而不是哪台设备。 JA4 是 2023 年发布的改进版，把哈希拆成可读的分段，更难规避。 CDN 和风控系统大量用它识别伪装成浏览器的自动化脚本： UA 写着 Chrome、TLS 握手却像 Python requests，很容易被识别出来。

说明：JA3 / JA4 必须由能读到 TLS 握手原始报文的服务端计算，本站的 Web 服务器拿不到这一层。 所以这个选项会由你的浏览器直接向第三方 TLS 回显服务发一次请求并取回结果。 这次请求不经过本站，本站也不接收、不保存返回内容。不想产生这次外部请求，不选这一项即可。

指纹被用来做什么

  • 风控与反欺诈：银行、支付、电商用它识别同一台设备下的批量注册、薅羊毛、盗号登录。这是指纹技术最主要也最正当的用途。
  • 广告追踪：在第三方 Cookie 逐步退场之后，指纹成了跨站追踪的替代方案——你在 A 站看过的商品，会在 B 站的广告位里出现。
  • 反爬虫：JA3 / JA4 尤其常用，用来分辨真实浏览器与伪装的自动化脚本。
  • 账号关联：平台据此判断多个账号是否来自同一台设备，用于封禁小号或识别刷单团伙。

怎么降低被指纹识别的可能

  • Tor Browser：目前最彻底的方案。它不靠隐藏，而是让所有用户看起来都一样：统一窗口尺寸、统一字体列表、屏蔽 Canvas 读取。
  • Firefox 的 resistFingerprinting：在 about:config 里把 privacy.resistFingerprinting 设为 true，会伪装时区、屏蔽 Canvas 与 WebGL 读取。副作用是部分网站显示异常。
  • Brave：默认为每个站点、每次会话给 Canvas 和音频信号加入随机噪声，让指纹在站与站之间对不上号。
  • 指纹浏览器：多开场景下常用的工具，为每个环境配置一套独立且自洽的指纹参数。

有一点和直觉相反：装一堆反指纹插件，可能反而更容易被认出来。 Canvas 结果随机、UA 改成十年前的版本、WebGL 被屏蔽， 这种组合在统计上非常少见，本身就成了一个显眼的指纹。 有效的做法是和大多数人看起来一样，而不是让自己与众不同。

常见问题

无痕模式能防指纹吗？
不能。无痕模式处理的是本地痕迹：不保存历史记录、退出时清除 Cookie。指纹不依赖任何保存的数据，它读的是硬件与系统属性，无痕窗口里这些属性完全一样。可以开一个无痕窗口打开本页对照。
换个 IP 或挂上 VPN，浏览器指纹会变吗？
不会。FingerprintJS v3 与 v2 计算的是浏览器与设备本身的属性，和网络出口无关；JA3 / JA4 计算的是 TLS 握手，同样与 IP 无关。所以指纹能把不同 IP 下的同一台设备关联起来。
为什么每次刷新，旧版算出来的值都不一样？
旧版依赖的部分信号（尤其是 Canvas）在开了反指纹保护的浏览器上每次都会被加噪，所以结果不稳定。这也说明你的浏览器确实开着某种防护。
本站会保存我的浏览器指纹吗？
不会。v3 与 v2 完全在你的浏览器里计算，结果不发回本站。JA3 / JA4 需要向第三方 TLS 回显服务发一次请求，结果同样只留在当前页面，不经过本站服务器。
