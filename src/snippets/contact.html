联系我们

数据勘误、功能反馈、合作洽谈，都欢迎通过下面的方式联系。本站没有客服系统， 邮件由维护者直接阅读，一般 1-3 个工作日内回复。

邮件

hi@judgeip.com

为了让问题能被快速定位，建议按下面的格式写：

  • 数据勘误：具体的 IP 地址、你认为有误的字段、以及你掌握的依据（比如你是该 IP 的使用方，或拥有更权威的数据源）。我们会逐项核对上游原始记录后回复。
  • 功能故障：出问题的页面地址、浏览器与版本、复现步骤，有截图更好。
  • 上游数据源事宜：如果你是本站引用的某个数据源的所有方，对数据使用方式有疑问，请直接说明，我们会优先处理。
  • 合作与 API 用量：目前的免费额度写在 API 文档里，超出免费层的批量需求可以邮件详谈。

安全问题

如果你发现了安全漏洞（比如能绕过限流、读取他人查询记录或篡改评分）， 请同样发往 hi@judgeip.com，标题加上「安全」。 请不要在漏洞修复前公开细节。本站没有漏洞奖励计划，但我们会在修复后公开致谢（除非你希望匿名）。

滥用投诉

本站的查询结果都是公开数据的聚合，不托管任何用户内容，也不提供代理或 VPN 服务。 如果你认为某个页面仍然侵犯了你的权益，请邮件说明具体页面与理由，我们会在核实后处理。

回复时效

邮件一般 1-3 个工作日内回复。数据勘误类的问题可能需要先向上游数据源求证，耗时会更长一些； 如果一周内没有收到回复，可以再发一次——邮件不会被故意忽略。
