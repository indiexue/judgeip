关于 JudgeIP

JudgeIP 是一个 IP 情报与网络检测工具站。它回答的问题很具体：你当前使用的这个 IP， 在各类平台的风控眼里大概长什么样——是家庭宽带还是机房，是原生注册还是广播租用， 有没有出现在公开黑名单里，是否被某些来源标记为代理或 VPN。

这个站为什么存在

做跨境业务、远程办公或者只是想安安静静用个 AI 服务的人，大多遇到过同一件事： 网络明明是通的，平台就是不放行。原因通常不在「能不能连」，而在于你的出口 IP 本身—— 它的注册归属、历史信誉和被标记记录。这类信息公开分散在各家数据库里， 普通用户没有趁手的工具把它们一次查清。JudgeIP 把这件事做成了一次查询： 输入或打开即测，每一项结论后面都附它是从哪个数据源、哪条记录得出来的。

本站怎么工作

  • 打开即测，不需要注册，没有账号体系，不收集姓名、邮箱、手机号。
  • 每次查询由服务器实时聚合十余个公开数据源：地区互联网注册机构（RIR）的注册记录、BGP 路由与 RPKI 签名状态、四个 DNSBL 黑名单、IPsum 威胁名单、Shodan InternetDB 以及若干 IP 情报服务。
  • 评分规则完全公开，每一项加减分都能在评分规则页核对；数据来源和缓存方式写在数据说明页。
  • 全站运行在 Cloudflare 边缘节点上，查询就近执行，结果按 IP 短暂缓存以减少对上游的重复请求。

评分不是判决书

本站给出的是「参考评分」：它描述这个 IP 在公开数据里的客观特征，不代表任何平台的实际放行结果。 各平台的风控口径互不公开、随时调整，还会参考账号行为、设备指纹等本站看不到的信号。 一个高分的 IP 不保证通过任何平台，一个低分的 IP 也不等于不能做正经事——它只是提示你， 这个地址在公开记录里长什么样。统计样本与排名同样只反映本站的查询记录，不是全互联网的画像。

这个站怎么赚钱

目前不赚钱。没有广告，没有付费墙，核心功能全部免费且无需注册。 如果未来引入任何形式的商业化（广告、增值服务或推广合作），会在这里和服务条款中明确写出， 且永远不会把查询内容、查询历史或访客信息卖给任何人——这一点在隐私政策里有完整约束。
