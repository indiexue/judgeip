什么是全球 Ping

Ping 是最古老也最常用的网络诊断命令：向目标发一个 ICMP Echo 请求，等它回一个 Echo 应答， 一来一回花的时间就是往返延迟（RTT），没等到应答的比例就是丢包率。 但你在自己电脑上敲 ping，测到的永远只是「从你这里」到目标的那一条线路。

全球 Ping 把同一个动作搬到世界各地：由分布在不同国家、不同运营商网络里的探针同时 Ping 同一个目标， 结果并排放在一起。选购海外服务器之前看看它到国内和到目标用户所在地的延迟， 网站上线后确认各地访客连过来快不快，CDN 切换之后检查各地是不是都命中了就近节点， 或者只是想确认是自己这边网络有问题，还是对方服务器真的挂了。这些问题单靠本机 Ping 都回答不了。

本页的探针来自 Globalping， 一个由 jsDelivr 团队维护的开源、免费探针网络，探针由世界各地的志愿者与机构自愿部署。

这次检测做了什么

  1. 在你的浏览器里检查输入：只接受公网 IPv4 / IPv6 地址或带点的域名，内网、保留地址与 localhost 会被直接拦下。 粘贴整条网址也可以，脚本会从中取出主机名。
  2. 浏览器直接向 Globalping 提交一次测量：13 个地区每处要 1 台探针，每台发 3 个包； 选 TCP 时改为与目标 443 端口握手 3 次。
  3. 每秒向 Globalping 取一次进度，哪台探针先测完就先填哪一行，全部完成或约 30 秒后停止。
  4. 汇总出可达节点数、最快与最慢的地区，以及目标在各地解析到的地址。

域名由探针在当地自行解析，不是在你的电脑上解析好再发过去。 所以使用了 GeoDNS 或 CDN 的网站，在不同地区可能解析到不同的地址。 「解析地址」一栏列出了这次各地拿到的全部地址，行内也会标出与多数节点不同的那一个。

怎么读检测结果

  • 平均延迟是三次往返的平均值，颜色分四档： 100 ms 以内为优（同城或近邻地区通常只有几毫秒到几十毫秒），100–200 ms 为良， 200–350 ms 偏慢（跨洲线路的常见水平），350 ms 以上为差。
  • 最小与最大差距很大说明线路抖动明显，延迟敏感的业务（游戏、语音、远程桌面）会感觉到卡顿。
  • 丢包率不为 0 时单独标出。3 个包丢 1 个就是 33%，偶发一次不必太在意，多个地区同时丢包才值得排查。
  • 不可达表示这台探针的包全部没有收到回应。ICMP 模式下最常见的原因是目标屏蔽了 Ping， 切换到 TCP 443 再测一次；TCP 也不通，才说明那个地区确实连不上目标。
  • 暂无可用探针表示 Globalping 这一刻在那个地区没有在线探针，与目标无关，过一会儿再测即可。

每一行都会写出实际执行测量的探针所在城市、AS 号与运营商。同一个地区下次测可能换一台探针， 数值也会随之变化。比较两次结果时，先看是不是同一家运营商。

常见问题

为什么有的节点显示「不可达」，网站却明明打得开？
ICMP Ping 和打开网站走的不是同一种流量。很多服务器、云主机的安全组和企业防火墙默认丢弃 ICMP，于是 Ping 全部超时，但 80 / 443 端口照常提供服务。遇到这种情况把方式切到「TCP 443」再测一次：TCP 能通就说明服务器在线，只是不回应 Ping；TCP 也不通，才说明目标在那个地区确实连不上。
ICMP 和 TCP 443 两种方式有什么区别，该选哪个？
ICMP 是传统的 Ping，测的是网络层一来一回的时间，适合看线路本身的质量。TCP 443 测的是与目标 443 端口完成三次握手的时间，不受 ICMP 过滤影响，更接近浏览器打开一个 HTTPS 网站时的建连耗时，数值通常与 ICMP 相近或略高一点。测服务器线路先用 ICMP，测网站或遇到「不可达」时用 TCP。
提示测量额度用完了是怎么回事？
Globalping 的匿名接口按你的出口 IP 计额度，每小时大约 250 个「探针·次」，本页一轮测 13 个节点就消耗 13 次，相当于每小时能测十几轮。额度按小时滚动恢复，等一会儿再试即可。请求是从你的浏览器直接发出的，额度只属于你自己，不会被其他访客用掉。
中国大陆节点为什么经常没有结果，或者每次城市都不一样？
Globalping 的探针由志愿者和机构自愿部署，中国大陆的公开探针数量很少，在线也不稳定。每次测量都从当前在线的探针里随机挑一台，所以城市与运营商可能每次不同，请以行内显示的城市和 AS 号为准；某个地区恰好没有在线探针时，那一行会显示「暂无可用探针」。
本站会记录我 Ping 过的目标吗？
不会。测量请求由你的浏览器直接发往 Globalping（api.globalping.io），本站服务器既不转发，也收不到你填写的目标。开始测量后地址栏会变成 /ping#host=…，方便刷新或转发时预填：# 之后的部分是网址片段，浏览器不会把它随请求发给本站，所以不会出现在本站的访问日志里。只有早期 /ping?host=… 形式的旧链接例外：问号之后的查询串是请求的一部分，打开那一次会和任何一次访问一样记进标准访问日志，页面随即把地址改写成 # 形式。需要知道的是：Globalping 作为第三方会收到你填写的目标和你的 IP 地址，测量结果会在它的平台上按其政策保存一段时间，任何拿到测量 ID 的人都能查看。
